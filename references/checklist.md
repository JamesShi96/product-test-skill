# 测什么

## 用户视角的问题（每个页面都问自己）

- 第一眼能看懂这页是干嘛的吗？下一步该点哪里明显吗？
- 我做了一个操作，产品有没有给反馈（加载中、成功、失败）？
- 出错时，提示能看懂吗？告诉我怎么办了吗？
- 完成这件事要走几步？有没有多余的步骤、重复填写？
- 有没有让我犹豫、不敢点、怕点错的地方？
- 文案像人话吗？有没有内部术语、英文残留、占位文字？
- 如果我是第一次来，会在哪里放弃？

## 能不能用

- **功能**：按钮/链接点了有没有反应，表单能不能提交，数据保存后刷新还在不在，删改是否生效
- **流程**：完整走下来会不会断，返回 / 刷新 / 重复点击后状态对不对，多个标签页同时开会不会出问题
- **边界**：空状态、超长文字、特殊字符和 emoji、超大文件、错误格式、网络慢或断开
- **报错**：console 里的 error、失败的请求（4xx / 5xx）、未处理的异常
- **登录态**：未登录访问受保护页面、登录过期后操作、退出后再返回

## 好不好用

- **视觉**：错位、重叠、截断、裂图、字体颜色不一致、深色模式下看不清
- **速度**：首屏加载、操作后多久有反馈
- **无障碍**：只用键盘能不能完成主要操作，焦点是否可见，图片有没有替代文字

## 只在整体测试时额外看

- 新用户首次体验：注册 / 引导 / 第一次完成核心任务的路径
- 各功能之间风格和交互是否一致
- 帮助、设置、账户等边角页面是否可用
- 和用户心里的预期比，缺了什么明显该有的功能

## 按产品类型额外看

只看和这次产品相关的那几类。

### 网页 / Web 应用
- 手机宽度（375px）下布局、按钮能不能点到、有没有横向滚动条
- console 报错、失败的网络请求（4xx / 5xx）
- 浏览器前进后退、刷新后状态还在不在；直接打开深层链接能不能进
- 多个标签页同时开、登录过期后操作

### 手机 App（iOS / Android）
- 系统权限弹窗（相机、相册、通知、定位）：拒绝后还能不能用，有没有引导去设置
- 切到后台再回来、来电打断、锁屏后回来，进行中的任务和输入还在不在
- 进行中的长任务（上传、识别、导入、读取）：切到别的底部标签再回来、点返回、退到后台再回来，进度还在不在，有没有卡住不动、页面变空白、丢掉已完成的部分；离开时的提示有没有说清后果（不是笼统的"未保存的修改"）
- 教用户操作系统的说明（手势、按钮位置）是不是所有机型都对：比如有 Home 键的 iPhone，控制中心从屏幕底部往上滑
- 断网、弱网、飞行模式下的提示和恢复
- 键盘挡住输入框、小屏机（iPhone SE）和大字体下的布局、深色模式
- 首次安装和升级安装都走一遍；卸载重装后数据是否按预期

### 桌面应用
- 窗口缩放、最小尺寸、多显示器；系统菜单和快捷键
- 拖拽文件进来、打开 / 保存对话框、退出时有没有未保存提醒
- 关掉重开后设置和数据还在不在

### 命令行工具
- `--help` 能看懂吗，有没有例子；参数写错时提示能不能指出哪里错、怎么改
- 退出码：成功是 0，失败非 0；错误信息走 stderr
- 管道输入输出、非交互环境（CI）里能不能跑，会不会卡在等输入
- 路径里有空格或中文、文件不存在、没权限

### API
- 状态码对不对（参数错 400、没登录 401、没权限 403、找不到 404），错误返回格式统一、有可读的原因
- 没登录、登录过期；拿别人的 ID 访问别人的数据（只在自己的产品上，用自己的两个测试账号）
- 必填字段缺失、类型错、超长、重复提交（幂等）
- 文档里的例子照着调能不能跑通

### 小程序
- 首次打开的授权弹窗（手机号、头像、定位）：拒绝后还能不能用
- 从分享卡片、扫码、搜索进来，落到的页面对不对、能不能回到首页
- 切出去再回来、被微信回收后重新打开，状态还在不在
- 和 iPhone 刘海、底部横条、微信右上角胶囊按钮有没有重叠

### 浏览器扩展
- 安装后第一次打开的引导、权限申请说得清不清楚
- 在不同网站上是否正常、会不会影响网页本身
- 浏览器重启、扩展更新后设置还在不在

## 评测维度

体验评测时逐项给判断（好 / 一般 / 差 + 一句话理由 + 证据）。和本次要回答的问题无关的维度可以跳过，但要说一声。

| 维度 | 看什么 |
|---|---|
| 第一印象 | 5 秒内能看懂这是干嘛的、给谁用的吗？下一步点哪明显吗？ |
| 上手 | 注册和引导要几步？多久能完成第一次核心任务？中间有没有被要求填一堆东西 |
| 核心任务 | 3–5 个真实任务各走了几步、多久、在哪卡住；结果是否达到预期 |
| 可靠 | 有没有报错、卡死、丢数据、结果时好时坏 |
| 速度 | 打开、操作反馈、生成结果各要多久 |
| 文案和信任 | 说人话吗？价格、扣费、隐私、数据怎么用讲清楚了吗？有没有诱导点击、隐藏的付费墙、难找的取消订阅 |
| 设计一致 | 各页面风格、按钮位置、叫法是否统一 |
| 多端和适配 | 手机 / 平板 / 桌面、深色模式、大字体下是否可用 |
| 无障碍 | 键盘或读屏能否完成主要操作，对比度够不够 |
| 差异化 | 和同类产品比，它最强和最弱的地方是什么；用户为什么会选它或不选它 |
